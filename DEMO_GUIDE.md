# Quick Demo Guide
## 🚀 Running the App
### For Web (Recommended for Demo)
```bash
flutter run -d chrome
```
### 📸 Demo Flow
1. **Show Home Screen** - Custom-drawn mood faces
2. **Log Moods** - Click several moods, show timeline
3. **View Statistics** - Click chart icon, show analytics
4. **Show Persistence** - Close and reopen app
5. **Highlight Code** - Show CustomPainter, tests, structure
## 💬 Key Points
- CustomPainter draws all faces from scratch
- fl_chart provides data visualization
- SharedPreferences persists data
- Provider pattern for state management
- 90%+ test coverage
- Production-ready web build
